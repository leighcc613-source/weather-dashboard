# weather-dashboard
A weather dashboard that fetches data from a public weather API.

## Features
- Search for a city
- Load current weather conditions
- View hourly forecast
- View a 7-day forecast
- Use browser geolocation to detect the user’s location

## Tech stack
- HTML
- CSS
- JavaScript
- Open-Meteo API for weather and geocoding data

## Run locally
1. Open `index.html` in a browser, or
2. Serve the project with a local web server:

```bash
python -m http.server 8000
```

Then visit: http://localhost:8000

## Notes
This project uses the public Open-Meteo API, which does not require an API key.
